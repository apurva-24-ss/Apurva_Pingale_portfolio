---

## 🌟 Highlights

- **Interactive UI**: Responsive design with dynamic sidebar, smooth scrolling, and scroll-spy navigation.
- **Dynamic Typing Animation**: Interactive hero section highlighting core technical competencies.
- **Filterable Projects**: Categorized showcase covering GenAI & Multi-Agent systems, Deep Learning, and MLOps.
- **Skill Proficiency Bars**: Animated progress bars on viewport intersection.
- **Interactive Endorsements Modal**: Allows colleagues and mentors to submit references directly.
- **Direct Contact System**: Web3Forms integration for real-time contact and feedback routing.

## 🚀 Getting Started

To run the portfolio locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/apurva-24-ss/Apurva_Pingale_portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Apurva_Pingale_portfolio
   ```
3. Open `index.html` in your favorite web browser or start a local server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
